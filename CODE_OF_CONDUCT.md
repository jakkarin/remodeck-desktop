# Code of Conduct

Help make this project a respectful place to collaborate, regardless of experience, background,
identity or language. English and Thai are both welcome.

- Discuss ideas and code constructively; respect people and differing perspectives.
- Do not harass, threaten, discriminate, publish others' private information, or use sexualized abuse.
- Respect maintainers' decisions about scope and the time volunteers can offer.

These expectations apply to project issues, pull requests and other official project spaces.
Maintainers may edit or remove inappropriate content, close discussions, or restrict participation
according to the severity and recurrence of the behavior.

For a conduct concern, contact the maintainer through an existing private collaboration channel.
No dedicated conduct contact email is currently designated. Keep personal or sensitive details out of
public issues. You can also use
[GitHub's abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
